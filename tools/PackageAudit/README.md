# 包与模型清单审核

在仓库根目录运行：

```powershell
python tools/audit-package.py
```

脚本先用 `dotnet pack -c Release --no-build` 打包已有 Release 产物，再核对包内 DLL/XML 与编译目录的哈希、包内文档、NuGet 依赖、托管 PE 标志、程序集引用及本地模型清单。主库应提前完成 Release 构建；本工具不执行模型、不测量性能。Python 控制脚本只使用标准库，.NET 辅助项目只使用框架程序集，两者均不是主库的运行依赖。

结果和日志位于 `artifacts/validation/<版本>/`。报告列出每个模型的实际大小与 SHA256，并核对上游许可证全文的原始字节及来源声明。审核现有安装包可以加 `--skip-pack`；可用 `--package`、`--compiled-dir`、`--output` 指定产物位置。更新 README 或 VALIDATION 后，应重新执行默认命令，使包内文档和报告哈希同步更新。

XML 检查的范围是编译生成的成员和能反射匹配的声明：核对中文 summary、参数名、非 void 返回值及属性说明。void 方法与构造函数无需 returns。位置 record 的属性说明由编译器从参数注释生成，通常只有 summary；这些成员会单列，避免误报为手写属性缺少 value。只由类型说明覆盖的公开无参构造函数也会单列，因为反射不能区分隐式默认构造函数与显式空构造函数。

报告保留未映射成员和实际缺项，不声称全部源码声明、异常传播路径或文档质量达到 100%。exception 检查只统计已有标签和中文描述；模型来源与许可证检查只核对本地文件、清单和原始字节，不推断许可证兼容结论。`passed` 表示上述明确范围内没有待修正项目。
