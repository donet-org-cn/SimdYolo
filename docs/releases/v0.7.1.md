# SimdYolo 0.7.1：中文代码文档与 YOLO 模型

这是历史发布版本。当前代码、模型和性能结果请查看[最新发布](https://github.com/hnlyf168/SimdYolo/releases/latest)及[仓库首页](https://github.com/hnlyf168/SimdYolo)。

## 本版本内容

- 纯 C# / .NET 10 YOLO 推理，CPU 使用 SIMD/intrinsics，GPU 调用系统 Vulkan/Metal API。
- 直接加载支持范围内的 `.pt` 和 ONNX，覆盖检测、实例分割与姿态估计。
- 补齐类、方法、参数、返回值、属性和异常的中文 XML 文档；NuGet 包包含 `SimdYolo.xml`。
- 0.7.1 的 Release 构建无警告、无错误，CPU/Vulkan 与真实模型测试共 90 项通过。
- 0.7.1 与 0.7.0 的 1,636 个方法签名、IL、局部变量和异常区域一致；本版本沿用 0.7.0 冻结程序集的性能测量，未把旧测量标成新一轮基准。

## 下载

| 附件 | 用途 |
| --- | --- |
| `SimdYolo.0.7.1.nupkg` | 推理主库及中文 IDE 文档 |
| `SimdYolo.0.7.0.nupkg` | 当时正式性能测量对应的历史库包 |
| `SimdYolo-models-v0.7.1.zip` | 24 个模型：8 个 PT、16 个 ONNX，以及原许可证和来源 |

旧模型包的 opset 12 ONNX 使用固定 128×128，普通 opset 17 ONNX 使用 640×640；请按实际模型输入运行。此历史版本不包含后续新增的 YOLO26、训练模块和网页示例。

模型沿用上游 **AGPL-3.0**，源码未新增许可证。Metal 已有实现，当时 Windows 环境未进行 Metal 实机验证。
