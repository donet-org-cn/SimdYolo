# SimdYolo 0.9.0：纯 C# YOLO 推理、检测头微调与网页版

主库和训练核心使用 C# / .NET 10，CPU 使用 SIMD/intrinsics，GPU 调用系统 Vulkan/Metal API。运行时无需 Python、PyTorch、TorchSharp、ORT 或原生数学库；Vulkan 路径无需 CUDA Toolkit、cuDNN、cuBLAS。

## 本次发布

- 已验证 YOLOv8n、Ultralytics YOLOv9t、YOLOv10n、YOLO11n、YOLO26n 检测，以及 v8/11/26 的分割、姿态推理。
- 直接读取完整受支持 `.pt` 和 ONNX，独立读取类别标签；模型包包含全部33个模型、原许可证和来源清单。
- 独立纯 C# 训练模块：YOLOv8 检测头微调，骨干/FPN 冻结，自定义类别、真实反向、SGD 动量、取消和断点恢复。
- `.sytrain` 自包含检查点可直接推理及恢复；Vulkan 训练为 GPU GEMM 与 CPU BN/损失/SGD 的混合路径。
- ASP.NET Core 网页示例：图片推理、数据集导入、真实损失曲线、任务记录、取消/恢复、模型下载和重新加载。
- README、公众号、博客园文章及性能图更新为本版本；历史报告和冻结包保持原版本与摘要。

训练当前不包含全参数、YOLO26、分割/姿态或 Metal 训练。未进行训练性能或独立验证集 mAP 测量。Metal 有推理实现，本轮没有 macOS 实机验证。

## 当前版本 CPU/GPU 实测

2026-10-15 10:53:49 +0800，i7-8700K / GTX 1050 Ti，FP32、batch=1、640×640、12线程。11模型×8配置×2轮，176个独立窗口，39,134次推理，224项输出校验通过；每配置预热60次，计至少4秒/40帧。

## 启动网页版

源码方式需要 .NET 10 SDK 和已拉取的 Git LFS 模型：

```powershell
dotnet run --project examples/SimdYolo.Web -c Release
```

打开 **http://127.0.0.1:5188**。运行包方式将网页ZIP和模型ZIP解压到同一目录，安装ASP.NET Core 10运行时，然后运行包内 `start.cmd`（Windows）或按README启动。默认本机绑定，没有公网账号/鉴权。
