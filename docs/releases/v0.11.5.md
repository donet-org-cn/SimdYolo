# SimdYolo 0.11.5

## 中文

`SimdYolo` 和 `SimdYolo.Training` 同步发布 0.11.5，目标框架为 .NET 10。训练包的推理依赖同步更新。

- **ARM64 CPU** 为普通卷积和逐点卷积添加 NEON 分块路径，按需打包输入，并在同一输出块中处理偏置和 SiLU。
- **CPU INT8** 按硬件使用 AVX-VNNI、AVX2、Arm DotProd 或 NEON 计算有符号点积。支持的 512 位 INT8 和 FP32 GEMM 内核需显式启用。默认推理仍为 FP32。
- **模型兼容** 支持单输出 ONNX `MaxPool` 和 PyTorch `MaxPool2d` 的 `ceil_mode`，并在 ONNX 导出中保留正确的填充和池化属性。
- **车牌 OCR** 新增 `ModelExporter.ExportPlateRecognizerOnnx(Stream)`，可将 `chinese-plate-recognition` 的 PlateNet 字符权重转换为 ONNX，供 OCR 运行时进行 CTC 解码。
- **Android Vulkan** 使用 Android 系统的 `libvulkan.so` 加载 Vulkan 后端。

### AVX-512 实测

AVX-512 默认关闭。具有相应指令集的机器可在启动进程前设置 `SIMDYOLO_CPU_AVX512=1`。在 Xeon Silver 4314 上，使用同一预发布 DLL、640×640 FP32 和 batch 1 测量两个模型。每个配置三轮共六个窗口，表中为稳态中位耗时。

| 模型 | 线程 | 关闭 | 开启 | 开启后的耗时变化 |
| --- | ---: | ---: | ---: | ---: |
| 车牌检测 ONNX | 1 | 130.10 ms | 140.38 ms | +7.91% |
| 车牌检测 ONNX | 4 | 48.41 ms | 49.75 ms | +2.76% |
| YOLOv8n PT | 1 | 133.51 ms | 138.29 ms | +3.58% |
| YOLOv8n PT | 4 | 49.51 ms | 52.70 ms | +6.44% |

四线程结果在共享主机上有轮间波动。单独测量的三种矩阵形状中，两种的耗时分别下降 5.91% 和 13.94%，一种增加 15.50%。144 项整模型输出对照均通过数值容差校验。

在 RTX 3060 上显式启用通用 ONNX 末轴 GPU TopK 时，0.11.4 和 0.11.5 均复现了同分索引差异。通用 ONNX TopK 默认走 CPU。[0.11.4 验证记录](https://github.com/donet-org-cn/SimdYolo/releases/tag/v0.11.4)

## English

Both NuGet packages target .NET 10 and ship as 0.11.5. The training package updates its shared inference dependency.

- **ARM64 CPU** adds NEON tiles for standard and pointwise convolutions, with on-demand input packing and bias and SiLU applied within each output tile.
- **CPU INT8** selects supported AVX-VNNI, AVX2, Arm DotProd, or NEON instructions for signed dot products. Supported 512-bit INT8 and FP32 GEMM kernels require explicit opt-in. Inference defaults to FP32.
- **Model compatibility** supports `ceil_mode` for single-output ONNX `MaxPool` and PyTorch `MaxPool2d`. ONNX export preserves pooling behavior and padding.
- **License plate OCR** adds `ModelExporter.ExportPlateRecognizerOnnx(Stream)` to convert the `chinese-plate-recognition` PlateNet character checkpoint to ONNX for CTC decoding in an OCR runtime.
- **Android Vulkan** loads the Vulkan backend through Android's system `libvulkan.so`.

AVX-512 is off by default. Set `SIMDYOLO_CPU_AVX512=1` before startup to opt in on supported hardware. The table above compares the same prerelease DLL with AVX-512 off and on. On a Xeon Silver 4314, enabling it increased median 640×640 FP32 inference time by 2.76–7.91% across two models tested with one and four threads. The four-thread results varied across rounds on the shared host. Two of three standalone matrix shapes improved by 5.91% and 13.94%, and one took 15.50% longer. All 144 model output comparisons passed their numeric tolerance checks.

On an RTX 3060, the opt-in generic ONNX last-axis GPU TopK returned different indices for tied scores in both 0.11.4 and 0.11.5. Generic ONNX TopK defaults to CPU. [0.11.4 validation](https://github.com/donet-org-cn/SimdYolo/releases/tag/v0.11.4)
