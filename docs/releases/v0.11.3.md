# SimdYolo 0.11.3

本版包含 CPU 最近邻上采样和最大池化优化，以及 Vulkan 张量拼接的批量传输优化。推理库和训练库统一使用版本 0.11.3，目标框架为 .NET 10。

- CPU 的 2 倍最近邻上采样复用同一组 SIMD 向量写入两行，省去列映射分配和输出行回读。最大池化预先计算窗口的有效边界，减少内层边界判断。
- Vulkan 在拼接前集中上传输入，一次同步后按源缓冲区批量提交拷贝区域。覆盖主机和设备输入、空输入、不同批次及重复输入。
- 包含本版本此前的启动改进：PT 模型解析与 BN 融合、ONNX 路由与工作区复用，以及进程内 Vulkan 实例复用。[启动验证与复现](../startup.md)

## 安装

```sh
dotnet add package SimdYolo --version 0.11.3
dotnet add package SimdYolo.Training --version 0.11.3
```

训练包会传递引入同版推理包。模型的来源、校验值和许可证见[模型清单](../../models/README.md)。

## 稳态推理实测

Windows、Core i7-12700、RTX 3060，FP32、640×640、batch 1，CPU 12 线程。使用仓库中的公交车样图，对比改动前后同为 0.11.3 的程序集。每种后端运行两轮 ABBA 顺序，每个版本共四个独立进程窗口，每窗口预热 50 帧。下表为各窗口中位耗时的中位数，包含原始输出回读。

| 模型 | 后端 | 改动前 | 改动后 |
| --- | --- | ---: | ---: |
| YOLOv8n PT | CPU | 25.19 ms | 25.18 ms |
| YOLOv8n PT | Vulkan | 4.44 ms | 4.36 ms |

该配置的 CPU 整体耗时持平，Vulkan 中位耗时下降约 2%。测量命令见[对照工具](../../tools/LifecycleBenchmark/README.md)。

## 发布流程

GitHub Actions 的 `nuget-release.yml` 可手动运行构建、测试和打包验证。推送与两个项目版本一致的正式版标签后，流水线通过 NuGet Trusted Publishing 上传同一批产物，回读 NuGet 上的包内容，然后发布 GitHub Release 与 SHA-256 清单。

首次发布前，在 GitHub 的 `nuget-release` 环境中配置变量 `NUGET_USER`，值为拥有两个包的 NuGet 个人或组织账户名。在 NuGet 的 Trusted Publishing 中授权仓库 `donet-org-cn/SimdYolo`、工作流 `nuget-release.yml`、环境 `nuget-release`，包名限定为 `SimdYolo` 和 `SimdYolo.Training`。[NuGet 官方配置说明](https://learn.microsoft.com/en-us/nuget/nuget-org/trusted-publishing)
