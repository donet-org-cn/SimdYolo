# SimdYolo 0.11.2：原版对照重测、纯.NET模型工作流与目标分离

主库和训练核心为纯C#/.NET10；CPU使用SIMD/intrinsics，GPU使用系统Vulkan/Metal。应用不依赖Python、PyTorch、TorchSharp、ORT或BLAS；Vulkan运行不需要CUDA Toolkit/cuDNN/cuBLAS或Vulkan SDK，需要兼容驱动和loader。Python/ORT仅供独立开发验证。

## 本版功能

- 直接加载受支持完整PT、ONNX、SYTRAIN及类别标签，检测/实例分割/姿态统一API，随包提供33份原模型。
- 纯C#掩码SIMD、坐标与插值行缓存、多实例有界并行、临时缓冲池；公开输出保持独立所有权。
- 网页人物/车辆分离和移除目标背景，两张互补透明PNG；4K/8K图有界缩放，原图坐标映射。
- RGB24二进制上传、有界掩码LRU、RGB复用；调整置信度复用模型会话。
- 五代检测头微调、独立验证集、P/R/mAP、最佳模型、早停、取消恢复；网页标注与人工审核预标注。
- 纯.NET导出标准ONNX；CPU FP16混合/INT8及校准为实验功能，当前没有速度优势，默认FP32，GPU仍为FP32。

## 原版 / 本库 / ORT速度排名

实测日期：2026-10-17 11:50:41 +0800；Intel(R) Core(TM) i7-8700K CPU @ 3.70GHz，NVIDIA GeForce GTX 1050 Ti。FP32、batch1、640×640、CPU12线程。11模型×8配置×两轮，共**176个独立窗口、39,264次推理、224/224项输出校验通过**。预热60次，每窗口至少4秒/40帧。

本表计入网络前向与输出头解码；GPU包含输入上传和全部输出回读，排除图片预处理、NMS、最终实例掩码、模型加载和首帧。原版PyTorch使用官方Ultralytics fuse()，ORT启用全部图优化，CUDA关闭TF32。每格为两个独立窗口中位数的中位数，①最快，按未舍入值排名；接近结果不能解释为稳定胜出。

## CPU / GPU 速度排名

每格为中位耗时 ms + 名次，①最快、④最慢，第一名加粗；重复窗口取各窗口中位数的中位数，按未舍入值排序。小幅差距不代表稳定胜出或统计显著性。

## 推理、训练与网页验证

推理CPU/Vulkan回归116项、训练集成19项及完整网页流程见[本版验证](https://github.com/hnlyf168/SimdYolo/tree/v0.11.2/artifacts/validation/0.11.2)。发布使用与正式计时相同的主库DLL，包、模型、网页、文档及中文UTF-8说明均核验摘要。训练速度及保存模型对照仍绑定0.10.1，没有冒充本版重测。

训练限于冻结骨干/FPN的检测头微调；没有全参数、分割/姿态或Metal训练。普通ONNX不能初始化训练；SYTRAIN是本项目归档，不能冒充PyTorch PT。其他尺度/设备需独立验证，Metal本机未测试。
