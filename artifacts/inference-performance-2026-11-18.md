# SimdYolo 推理性能对照（2026-11-18）

基线使用 NuGet 正式包 **SimdYolo 0.11.5**，候选使用当前源码的 Release 构建。完整图片推理在 CPU 上的中位耗时下降 3.6%–7.1%，累计 CPU 时间/帧从下降 6.6% 到增加 0.3%。Vulkan 的中位耗时下降 15.8%–31.7%，累计 CPU 时间/帧下降 26.3%–49.4%。 [NuGet 0.11.5](https://www.nuget.org/packages/SimdYolo/0.11.5)

8 组完整图片推理的托管分配下降 75.1%–99.8%，进程峰值工作集下降 3.0%–53.6%，窗口末工作集从下降 46.3% 到增加 27.6%。Vulkan 设备中间缓冲区容量下降 12.7%–26.6%。

## 本轮改动

- 图片推理在会话内复用 FP32 输入和仅供解码使用的张量。Vulkan 回读和命令重放都沿用该缓冲区池，解码结束后归还。共享缓冲区由会话锁保护。公开原始张量和分割概率数组交由调用方独立持有。
- 双线性缩放直接写入三个颜色平面，只填充图像边缘。通道优先检测输出以 SIMD 处理多个锚点的分类分数，按原有顺序处理同分、无效值和非极大值抑制。
- Vulkan Winograd 将卷积权重直接变换到实际使用的布局，卷积间复用乘积工作区。已有计算屏障覆盖读取和覆写，扩容时保留旧工作区到提交完成。 [Vulkan 同步说明](https://docs.vulkan.org/guide/latest/synchronization_examples.html)
- 张量常用路径减少重复形状校验和形状副本。单输出会话转移数组所有权时省去别名集合。

## 测量与输出核验

- 12th Gen Intel(R) Core(TM) i7-12700、RTX 3060、Windows-11-10.0.28000-SP0、.NET 10.0.15。两组以同样的 HighQoS 和亲和性运行，固定到 8 个不同 P 核的各一个硬件线程，CPU 推理线程数为 8。AVX-512 关闭。
- 16 个模型、后端和输入路径的组合。每组运行两轮 ABBA，每版本 4 个独立进程。每窗预热 40 帧，稳态至少 2.5 秒和 48 帧。共 **128** 个窗口、**36,062** 次稳态推理。报告使用各窗口中位数的中位数，P95 也按窗口汇总。
- CPU ms/帧为进程用户态与内核态累计 CPU 时间除以帧数，多个线程的时间相加。Vulkan 应用管线缓存关闭，操作系统文件缓存、显卡驱动缓存及形状调优按正常环境运行。
- 首帧和稳态末帧共 **364** 项输出对照，包含基线重复运行与候选组。**236** 项逐字节相同，其余均通过数值容差。原始张量最大绝对差 0.00302124，掩码概率最大差 5.00679e-06，框及关键点坐标最大差 0.00038 像素，置信度最大差 2.174e-05。
- 原始张量逐元素容限为 0.003 + 0.0003 × |参考值|，掩码概率为 0.001 + 0.0003 × |参考值|。预测结果按顺序核对实例数量、类别、关键点数量和掩码几何，坐标容限 0.02 像素，置信度容限 0.00005。
- 已通过 Release 构建、108 项 CPU 测试、11 项训练测试和 21 项定向 Vulkan 测试。其中包含切换图像尺寸和 BGR 行跨度、保持公开输出所有权、Winograd 扩容以及重放。
- 将 NuGet 0.11.5 的训练 DLL 与候选推理 DLL 一起运行，CPU 与 Vulkan 均通过训练、检查点恢复和推理。

## 复现

正式包通过 NuGet V3 下载。权重与项目自带的公交样图用于全部窗口，DLL、输入、权重和计时程序的 SHA-256 在汇总中记录。逐窗口文件保存首帧和末帧路径、输出哈希、每次耗时和容量读数。

~~~powershell
$env:DOTNET_PROCESSOR_COUNT = '8'
$env:SIMDYOLO_CPU_AVX512 = '0'
python tools/compare-lifecycle.py --baseline-dir .cache/overall-perf-2026-11-18/baseline --candidate-dir .cache/overall-perf-2026-11-18/candidate --models yolov8n yolo26n-seg --formats pt --backends cpu vulkan --threads 8 --windows-high-qos --windows-affinity 5555 --size 640 --warmup 40 --min-frames 48 --duration 2.5 --cache-mode disabled --repeats 2 --input .cache/overall-perf-2026-11-18/bus.rgb --rgb-size 810 1080 --output .cache/overall-perf-2026-11-18/repeat-image-pt.json
~~~

ONNX 对照选择 yolov8n 和 yolo11n-pose。纯模型对照用 .cache/perf-bus.f32 并省略图像尺寸参数。
