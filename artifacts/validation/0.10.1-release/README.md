# 0.10.1 发布验证

[中文发布说明](../../../docs/releases/v0.10.1.md)对应0.10.1主库、训练库、网页、33模型与中文图文包。[运行时数值与训练验证](../0.10.1/README.md)使用的最终DLL保持不变，采用`--no-build`打包/发布，避免Git提交信息引起程序集摘要漂移。

- `package-assets.json`核对两个NuGet、33模型ZIP、网页ZIP、文档ZIP与SHA256SUMS；每个模型在压缩前/解压后验证原始SHA256及大小。
- `package-consumers.json`记录独立本地NuGet消费：五模型CPU/Vulkan真实训练、恢复及原生模型推理；主库、训练库与冻结DLL摘要一致。不是用ProjectReference代替包消费。
- `web-package-api.json`记录解压后的网页包运行验证：版本、33模型、训练/恢复、上传下载、检测/分割/姿态、Vulkan、缓存会话与错误请求。
- 中文发布说明从UTF-8文件上传，回读须与本地完全相同。附件先上传草稿，逐个核对服务端摘要，最后发布；`release-publication.json`记录公开版本与实际下载校验。

历史0.9.0推理排名和0.10.0训练数据保留原版本，未伪称为本版重测。训练后模型差异保留未通过项：直接参数9/10、指标10/10、固定CPU参数控制10/10。源码未新增许可证，33模型保留原AGPL与来源。
