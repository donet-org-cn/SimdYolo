# SimdYolo 第二轮推理优化报告（2026-11-18）

同机交错对照本次测试时的最新 NuGet 正式包 0.11.5、上一轮候选 DLL 与本轮 Release DLL。全部使用 FP32，CPU 关闭 AVX-512。 [NuGet 正式包](https://www.nuget.org/packages/SimdYolo/0.11.5) · [上一轮报告](inference-performance-2026-11-18.md)

- **YOLO26n-seg PT CPU 前向**中位耗时为 37.98 → 38.98 → 36.82 ms。本轮每帧 CPU 时间比上一轮下降 13.3%，比 NuGet 0.11.5 下降 9.2%。
- **YOLO26n-seg PT Vulkan 完整图片推理**中位耗时为 8.78 → 8.11 → 7.84 ms。本轮比上一轮下降 3.4%，比 NuGet 0.11.5 下降 10.7%。
- **Vulkan 设备中间缓冲区**容量在 YOLOv8n PT 上为 224.00 → 164.39 → 140.30 MiB，在 YOLO26n-seg PT 上为 288.00 → 238.06 → 223.64 MiB。

## 本轮改动

- CPU 执行器在预算达到 4 线程时让空闲工作线程直接进入事件等待。调用线程继续参与计算，现有自旋参数仍可覆盖默认值。
- 大型连续拼接和同形状逐元素运算在 CPU 推理范围内按 128 KiB 连续区段交给已有执行器，保持原 SIMD 运算和公开张量布局。
- PT 端到端实例分割与姿态直接收集 TopK 入选锚点的附加字段。CPU 按特征层读取，Vulkan 从独立字段张量收集，省去与检测头的整图拼接。
- Vulkan TopK 用预计算的整数顺序键比较分数，移动堆头时少写共享内存。原始 FP32 位模式用于输出，覆盖同分、NaN、次正规值和有符号零。
- Vulkan Winograd 每帧复用两个输入变换槽及一个乘积工作区，扩容后在帧提交完成时释放旧缓冲区。

## 测量与校验

- i7-12700、RTX 3060、Windows-11-10.0.28000-SP0、.NET 10.0.15。两组输入均为 640×640 单帧模型尺寸。CPU 固定到 8 个 P 核各一个硬件线程，8 线程预算，子进程统一 HighQoS。Vulkan 应用缓存关闭。
- 10 种配置各运行 3 轮，版本顺序在三轮中循环，每版各占一次首位、中间和末位。每版本每配置 3 个独立进程，每窗预热 40 帧，稳态至少 2 秒及 40 帧。共 **90** 个窗口、**17,832** 次稳态推理。
- 表格各列取窗口指标的中位数。CPU ms/帧按所有进程线程的累积 CPU 时间除以帧数。逐窗归档保存每帧耗时、运行设置、数值输出的路径及 SHA-256。张量和掩码原始文件在本机实验缓存中。
- 对上一轮对应首帧和最后一帧共做了 **352** 项核对，其中 **132** 项来自本轮候选，**79** 项逐字节相同。全部通过各自的形状和数值校验。
- 张量最大绝对差 0.003051758，掩码概率最大差 4.947186e-06，坐标最大差 0.0003 像素。张量容差为 0.003 + 0.0003 × |参考值|，图像中实例数、类别和掩码几何逐项一致，坐标容限 0.02 像素。
- Release 构建、109 项 CPU 测试、136 项 CPU/Vulkan 全套测试和 11 项训练测试通过。此前在 RTX 3060 上失败的通用末轴 GPU TopK 用例也通过了本轮验证。
- 关闭 Winograd 输入变换缓存后，单槽工作区的扩容、布局切换和命令重放用例同样通过。
